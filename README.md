# スカウトメール自動生成 - グルメキャリー版

グルメキャリー管理画面（kanri.gourmetcaree.jp）の候補者詳細ページで、
ボタン一つで候補者情報を読み取り、Gemini がスカウトメール（件名・本文）を
自動生成してフォームに入力してくれる Chrome 拡張機能です。

リクナビHRTech版の拡張機能をベースに、グルメキャリー用に移植したものです。

---

## できること

- スカウト送信画面の左下に青い丸ボタンを表示（目立たないようラベルなし）
- クリックすると候補者情報（職務要約・スキル・職歴・希望条件など）を自動で読み取り
- Gemini のタブが自動で開き、古川さんのスカウトメールプロンプトで文面を生成
- 生成された **件名（70文字以内）** と **本文（4000文字以内）** をフォームへ自動入力
- 文字数チェック付き（件名 70 / 本文 4000 を超えると赤字で警告）
- その日に「送信」ボタンを押した件数をボタン横のバッジに表示（毎日0時にリセット）
  - **バッジをクリックすると「− ＋」で件数を手で直せます**（手作業で送った分の足し込み・数え間違いの修正用）
  - スカウト画面以外（会員検索・プロフィールなど）でも、**画面左下に件数の小さな丸**が出ます。
    同じようにクリックすると「− ＋」で直せます（一覧ページでは操作ボタンの右隣に並びます）
- **最後の送信ボタンは必ず人間が押す**設計です（誤送信防止）

## インストール方法（初回のみ・約3分）

1. このリポジトリの緑色の「**Code**」ボタン →「**Download ZIP**」でダウンロード
2. ZIPファイルを右クリック →「すべて展開」（好きな場所でOK。**展開後のフォルダは消さないこと**）
3. Chrome のアドレスバーに `chrome://extensions` と入力して開く
4. 右上の「**デベロッパーモード**」をONにする
5. 「**パッケージ化されていない拡張機能を読み込む**」をクリック
6. 手順2で展開した **gourmetcaree フォルダ** を選択
7. 一覧に「スカウトメール自動生成 - グルメキャリー」が表示されたら完了

> 更新版が出たときは、新しいZIPを同じ場所に展開し直して、
> `chrome://extensions` で拡張機能の「🔄（更新）」を押してください。

## 使い方

1. **Gemini（gemini.google.com）にログインしておく**（Googleアカウント）
2. **候補者のプロフィール画面を開く**（スカウト画面の宛先リンクから開ける）
   左下に「✓ プロフィール取得済み」と表示されたら、候補者情報が自動保存されています
3. スカウトメール入力画面に移る
4. 定型文を使う場合は、**先に**「定型文を選択」→「決定」を済ませる
   ※後から定型文を反映すると、生成した件名・本文が上書きされてしまうため
5. 画面左下の青い丸ボタンをクリック
6. Gemini のタブが自動で開き、生成が始まる（30秒〜1分ほど）
7. 生成が終わると元のページに自動で戻り、件名・本文が入力される
   ※本文欄に元から入っている「現在掲載中の求人情報はこちら」の求人リンクは、
   生成文の後ろに自動で残ります
8. 内容を確認して「送信」ボタンを押す（**送信ボタンは自動では押しません**）

> **なぜ先にプロフィール画面を開くのか**: グルメキャリーはプロフィール画面と
> スカウトメール入力画面が別ページで、入力画面には候補者の経歴情報がありません。
> そのため拡張はプロフィール画面を開いたときに情報を記憶し（会員IDごとに保存）、
> 入力画面では宛先IDと照合して使います。**未取得のまま生成しようとするとエラーで
> 止まる**ので、経歴なしの空メールが送られる事故は起きません。

## 全自動スカウト（バッチ処理）

会員検索の結果一覧から、候補者を1件ずつ自動で処理します（NG判定→生成→検証→送信）。
**件数の上限はありません。「止」を押すまで動き続けます。**

**使い方**
1. 会員検索で条件を絞り、検索結果一覧を表示する
2. 画面左下の丸ボタンを押す
   - **試**（グレー）: ドライラン。送信せずに生成と検証だけ行い、結果をレポートで確認
   - **動**（青）: 本番。検証を通過したメールを自動送信（開始前に確認ダイアログあり）
   - **再**（オレンジ）: 中断した処理を再開（スリープ復帰後など）
   - **止**（赤）: 停止。押すとその場で終了してレポートを表示
   - **報**（緑）: 前回のレポートを再表示
3. あとは放置でOK。1件あたり約1〜1.5分のペースで進みます
4. 「止」を押すか、そのページの候補者を処理し終えると終了し、レポート（送信/スキップ/理由の一覧＋生成メール全文）が表示される

**検索するときのコツ：表示件数を増やしておく**

一覧の右上にある表示件数を、検索した時点で「**100件**」など多めにしておいてください。
1回のバッチで扱える候補者が増え、長く回せます。

**自動ページ送り（有効）**

そのページの候補者を処理し終えると、**自動で次のページへ進みます**。

このサイトの「次へ」は画面の検索フォームを再送信する仕組みで、プロフィール画面を経由して
一覧に戻ると条件が空になり、「都道府県を選択してください」で止まってしまいます。
そこで拡張は**バッチを始めたときの検索条件をまるごと覚えておき、一覧に戻るときは
その条件で検索し直します**（画面の「次へ」を押すのではなく、同じ内容を送信し直す方式）。
ページ番号も指定して送るため、2ページ目以降へも直接進めます。

- **開始は必ず「この条件で検索する」を押した直後の一覧から**してください。条件が画面に入っている状態で「動」を押すと、それが記憶されます
- 開いているページが**処理済みの方だけでも中止しません**。対象がいるページが見つかるまで、自動でページを進めて探します（最大12ページ）
- それでも進めなかった場合は、処理を終了して「次のページへ進めませんでした（画面の案内: ◯◯）」と表示します。固まったままにはなりません
- 新しい候補者がいないページが2回続くと、候補者が尽きたと判断して終了します

**稼働中の進捗表示**
画面左下に進捗カウンターが常時表示されます（例：「送信 12件 / 処理済み 27件（スキップ 15 / エラー 0）」）。
途中でも何件スカウトしたかが一目で分かります。

**終了のしかた（どの画面からでも止められます）**
- 進捗カウンターの中の「**■ 停止**」ボタンを押す（プロフィール画面・スカウト画面など、どのページでもOK）
- 検索結果一覧なら **止**（赤）ボタンでも止まります
- **Geminiのタブを見ているとき**は、ツールバーの拡張機能アイコンを押して「■ 自動スカウトを停止」
- または、検索結果の候補者を最後まで処理し終えると自動終了

**スリープ・中断からの再開**

PCがスリープすると処理は止まりますが、**進捗は保存されています**（送信済みの記録も残ります）。
復帰したら次のどちらかで続きから再開できます。

1. **ページを再読み込み（F5）** … たいていはこれだけで自動的に続きが始まります
2. 動き出さない場合は **再**（オレンジ）ボタンを押す … 処理中だった候補者からやり直します

どちらの場合も、すでに送信した候補者には二度と送りません。
※ 長時間まとめて回すときは、PCの電源設定でスリープを切っておくと途切れません。

**自動でスキップされる候補者（NG判定）**
- 職種: パティシエ、寿司職人、ソムリエ、バーテンダー、パン職人・パン製造、バリスタ（過去経歴含む）
- キーワード: 特定技能、日本語能力（日本語検定）、JLPT
- **お名前が「すべてローマ字」または「すべてカタカナ」**（初期設定でON。下記参照）
- 飲食店経験年数が「未経験」
- 転職回数（経験社数−1）が年齢の10の位以上（例: 38歳で4社経験→NG）

一度NGになった方は記録され、次回以降の対象から外れます（「NG記録のリセット」で戻せます）。

**その回だけ見送る候補者（NG記録には残さない）**

次の方は「対象外」として処理をとばしますが、**NGとして記録しません**。
あとからご本人がプロフィールを書き足す可能性があるため、**次回のバッチでもう一度見に行きます**。

- **基本情報しか登録していない方**（経験値・希望条件・学歴・職務経歴がすべて空）
  レポートには「情報不足(基本情報のみ・詳細が未登録)」と残ります
- 年齢や社数が読み取れなかった方（「判定不能(…)」）

※ 経験値・希望条件・職務経歴のどれか1つでも記入があれば、通常どおり処理します。

**お名前による自動スキップ（初期設定でON・現状は動作しません）**

> **重要**: グルメキャリーの求職者プロフィールには**氏名の欄がありません**（会員IDのみ）。
> そのため、この判定は**現状どの候補者に対しても働きません**。
> 将来、氏名が表示される画面が出てきた場合に備えて機能だけ残してあります。

お名前が **すべてローマ字**（例: `NGUYEN VAN ANH`）または **すべてカタカナ**（例: `グエン ヴァン アン`）
の方は、最初から対象外になります。レポートには「NG氏名(ローマ字表記)」「NG氏名(カタカナ表記)」と残ります。

- 漢字・ひらがなが1文字でも混ざっている方は**対象に残ります**（例: `マリア 山田`）
- 「ふりがな」「氏名（カナ）」などの**読みの欄は見ません**（日本人の方まで外れてしまうため）
- お名前の欄が読み取れない候補者は、**判定せず対象に残します**（誤ってスキップしないため）
- 切り替えたいときは **語**（紫）ボタンの画面にあるチェックボックスをON/OFFして「保存」

> 日本人の方が多くはじかれてしまう場合（読みの欄を氏名と読み違えている可能性）は、
> このチェックを外して「保存」→ **NG記録をリセット**してください。

**NGワードを自分で追加する（コード変更不要）**

1. 検索結果一覧で、左下の **語**（紫）ボタンを押す
2. 開いた画面に、除外したい語を **1行に1語** ずつ書く（例: `ラーメン`／`アルバイト希望`）
3. 「保存」を押す

次のバッチからすぐ反映されます。プロフィールにその語が含まれる候補者はスキップされ、
レポートに「NGワード(◯◯)」と理由が残ります。削除したい語は行ごと消して保存してください。

**NG記録のリセット**

NG判定された方は記録され、次回以降スカウト対象から外れます（同じ人を毎回調べないため）。
ただし**NGワードを消しても、すでに記録された方は自動では戻りません**。

もう一度対象に含めたいときは、**語**ボタンの画面の下にある
「**NG記録をリセット（◯名）**」を押してください。記録された方が再び対象に戻ります。
**送信済みの記録は消えない**ので、すでに送った方に二度送ることはありません。

＜こんなときに使います＞
- NGワードを試しに追加したら、思ったより多くの人が弾かれてしまった
- 「未経験」だった方が経験を積んでプロフィールを更新した

**自動送信されない場合（検証ゲート）**
生成メールは3層で検証され、1つでも不合格なら再生成1回→それでもダメなら送信せずスキップされます。
①ルールベース（文字数・確定文破損・英単語混入・禁止語句など）②Geminiによる二次校閲（誤字・文の途切れ等）③不合格時の自動再生成。

**必ず最初はドライラン（試）で1バッチ回して、レポートの生成文を確認してから本番（動）を使ってください。**

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| ボタンが表示されない | ページを再読み込み（F5）する。それでも出ない場合は、スカウトフォームのある画面か確認 |
| 「入力エリアが見つかりません」エラー | Gemini にログインしているか確認。Gemini のタブを一度閉じてやり直す |
| 生成が120秒でタイムアウト | Gemini が混んでいる可能性。少し待ってもう一度ボタンを押す |
| 件名/本文が入力されない | Geminiのタブに生成結果が残っているので、そこからコピーして手動で貼り付け。その旨を開発者に連絡（画面のHTML構造が変わった可能性） |
| 文字数オーバーの赤字警告 | もう一度生成ボタンを押して再生成する |

## ファイル構成（開発者向け）

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の設定（対象サイト・権限） |
| `background.js` | グルメキャリー ⇄ Gemini のタブ間通信を仲介 |
| `content_gourmet.js` | グルメキャリー側の本体。候補者情報の抽出、生成ボタンUI、結果のクリーニング、フォーム自動入力。**スカウトプロンプトはこのファイルの先頭に記載** |
| `content_gourmet_main.js` | フォームへの値注入（MAIN world・SPA対応） |
| `content_gemini.js` | Gemini側の本体。プロンプト投入・回答の取得 |
| `content_gemini_main.js` | Geminiの入力欄（Quill）への文字列挿入（MAIN world） |
| `popup.html` | ツールバーアイコンを押したときの使い方説明 |
| `styles.css` | ボタン・ステータス表示の見た目 |
| `docs/01_分析と要件定義.md` | 本拡張の分析・要件定義ドキュメント |

### プロンプトを変更したいとき

`content_gourmet.js` の先頭にある `SYSTEM_PROMPT = \`...\`` の中身を書き換えて、
`chrome://extensions` で拡張機能を更新（🔄）してください。

### 注意事項

- グルメキャリー側の画面デザイン変更（HTML構造の変更）があると、
  候補者情報の抽出やフォーム自動入力が動かなくなる場合があります。
  その場合は `content_gourmet.js` のセレクタ調整が必要です。
- 本拡張は社内利用を想定しています。
